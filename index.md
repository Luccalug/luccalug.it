# Luccalug - Lucca Linux User Group


Benvenuti nel sito del **Luccalug**, il Linux User Group della provincia di Lucca!

Ci occupiamo di promuovere il **software libero**, condividere conoscenze su **GNU/Linux** e le tecnologie aperte, e creare una comunità di appassionati nella nostra zona. Non sai cosa aspettarti? [Leggi la guida alla prima serata]({{< ref "blog/guida-alla-prima-serata" >}})

**Incontri, workshop, installazioni guidate e tanto altro!**
