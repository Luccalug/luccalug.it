# Tango

**Data:** 22/11/2010

**Autore:** matteo

**Tag:** tango, django, progetti

---


È iniziata la fase di test del software Tango sviluppato dal LuccaLug con Django.

Il software viene utilizzato dalla Croce Verde di Ponte a Moriano per l'organizzazione dei turni dei volontari. Il software permette in maniera visuale di vedere quali turni sono scoperti e di trovare facilmente i volontari da contattare in base ad un completo sistema di statistiche.
