# Ubuntu Install Party, lunedì 2 aprile

**Data:** 29/03/2012

**Autore:** stefano

**Tag:** ubuntu, install-party, eventi

---


{{< evento titolo="Ubuntu Install Party" data="2012-04-02" luogo="Sede del LuccaLUG, Capannori (Lucca)" descrizione="Serata dedicata all'installazione di Ubuntu. Porta il tuo PC e ti aiuteremo a installare l'ultima versione di Ubuntu." >}}

Visto che abbiamo deciso di aggiornare la versione di Ubuntu sui computer del LuccaLUG, abbiamo pensato che chiunque potrà portare il proprio PC per installarci l'ultima versione di Ubuntu.

Quindi, se vuoi **provare Ubuntu su un nostro PC**, o se vuoi **aiuto per installare Ubuntu sul tuo portatile**, questa è la serata giusta!

{{< note type="info" >}}
La serata è aperta a tutti, soci e non. Portate il vostro PC e i dati di cui avete bisogno. Vi aspettiamo lunedì 2 aprile alle ore 21:15 presso la nostra sede.
{{< /note >}}
